# Hearthly (Agra) – React + Vite UI

    npm install
    npm run dev

UI/UX only: no backend. The form validates and shows a success state; nothing is sent.
Pages: one per navbar item (see `src/pages.jsx` and `src/routes.js`).
Images: every image address is in `src/images.js` (files in `public/images`).
Placeholders (brand, phone, WhatsApp, listings, team, stories, rates) are labelled on screen and live in `src/data.js`.
Hindi: `t(english, hindi)` is used inline. Missing Hindi falls back to English.
